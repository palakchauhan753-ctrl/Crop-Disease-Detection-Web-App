# AI-Based Crop Disease Detection Web Application

## Overview

The AI-Based Crop Disease Detection and Management System is designed to help users monitor crop health, identify plant diseases, and access useful information for crop management. It uses a deep learning model to detect diseases from uploaded leaf images and provides relevant solutions and recommendations.

## Key Features

### 1. Disease Detection and Solutions

Users can upload crop leaf images to identify possible diseases. The system predicts the disease using a trained deep learning model and provides relevant solutions or recommendations.

### 2. Weather Information

Provides weather information to help users monitor environmental conditions relevant to crop management.

### 3. History

Maintains a history of previous disease scans so users can review their earlier results.

### 4. Voice AI Assistant

Allows users to interact with the application using voice commands for a more convenient, hands-free experience.

### 5. Statistics Dashboard

Displays crop health statistics, including:

- Total number of scans
- Number of healthy plants
- Number of diseased plants
- Most commonly detected disease

### 6. Disease Library

Provides information about different plant diseases and suggests actions or management measures to help control them.

## Technologies Used

- **Frontend / Mobile App:** Flutter
- **Programming Languages:** Dart, Python
- **Backend:** Flask
- **Deep Learning:** TensorFlow, Keras
- **Model Architecture:** Convolutional Neural Network (CNN)
- **Database / Storage:** Firebase

## How It Works

1. The user uploads a crop leaf image.
2. The trained model analyzes the image and predicts the possible disease.
3. The application displays the prediction and relevant recommendations.
4. Users can explore weather information, previous scans, voice commands, crop health statistics, and the disease library.

## Installation and Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/palakchauhan753-ctrl/Crop-Disease-Detection-Web-App.git
   ```
2. Navigate to the project folder:
   ```bash
   cd Crop-Disease-Detection-Web-App
   ```
3. Install dependencies listed in the project's requirements file:
   ```bash
   pip install -r requirements.txt
   ```
4. Run the application using the correct Flask entry-point file for this project.
